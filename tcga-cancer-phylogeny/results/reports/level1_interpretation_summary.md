# Level 1 Interpretation and Sensitivity Summary

This analysis interprets the Level 1 TCGA pan-cancer molecular similarity dendrograms by cutting the Gower and correlation average-linkage trees at k = 3 through k = 8, summarizing molecular traits within clusters, testing feature associations with the Gower k = 6 clustering, and comparing feature-class and weighting sensitivity runs. Cluster stability is summarized from feature-bootstrap project-pair co-clustering frequencies.

The Gower k = 6 tree separates projects into clusters labeled as: cluster 1 (GI carcinoma enriched: ACC;CHOL;GBM;KICH;KIRC;KIRP;LAML;LGG;LIHC;MESO;PAAD;PCPG;PRAD;SARC;TGCT;THCA;THYM;UVM); cluster 2 (GI carcinoma enriched: BLCA;BRCA;CESC;COAD;ESCA;HNSC;LUAD;LUSC;OV;READ;STAD); cluster 3 (hematolymphoid outlier: DLBC); cluster 4 (high mutation burden / immune-active outlier: SKCM); cluster 5 (gynecologic outlier with distinctive molecular profile: UCEC); cluster 6 (gynecologic outlier with distinctive molecular profile: UCS). These groups should be read as projects that cluster with similar scaled molecular trait values, not as evolutionary lineages.

The correlation k = 6 tree separates projects into clusters labeled as: cluster 1 (kidney/CNS/endocrine low-mutation cluster: ACC;CHOL;KICH;KIRC;KIRP;LGG;LIHC;MESO;PCPG;PRAD;THCA;UVM); cluster 2 (GI carcinoma enriched: BLCA;CESC;COAD;READ;STAD;UCEC); cluster 3 (mixed lineage cluster: BRCA;PAAD;SARC); cluster 4 (mixed lineage cluster: DLBC;LAML;THYM); cluster 5 (squamous-like carcinoma enriched: ESCA;HNSC;LUSC;OV;TGCT;UCS); cluster 6 (mixed lineage cluster: GBM;LUAD;SKCM). Correlation distance emphasizes similarity in each project's relative feature-profile shape across traits rather than absolute scaled levels.

The Gower and correlation trees differ because Gower distance is sensitive to absolute trait differences after feature-level normalization, whereas correlation distance can cluster projects that have parallel molecular profiles even when their overall mutation burden, copy-number burden, or expression-program magnitude differs.

Feature-driver analysis suggests that the strongest Gower k = 6 associations include: mutation_prevalence_BRCA2, mutation_prevalence_BRCA1, tmb_proxy_mean_nonsynonymous_count, mutation_prevalence_ALK, tmb_proxy_mean_total_mutation_count, tmb_proxy_median_nonsynonymous_count, mutation_prevalence_ERBB2, tmb_proxy_median_total_mutation_count, mutation_prevalence_PIK3CA, mutation_prevalence_MSH6. These associations are descriptive Kruskal-Wallis tests across tree-derived clusters, so they indicate traits that separate the observed clusters rather than causal drivers.

Feature-class sensitivity shows the closest agreement with the all-feature reference for: all_features (ARI 1.00); mutation_plus_expression (ARI 0.89); mutation_plus_copy_number (ARI 0.66); mutation_only (ARI 0.53); copy_number_plus_expression (ARI 0.41); copy_number_aneuploidy_only (ARI 0.18); expression_only (ARI -0.02). Weighting sensitivity changed clusters for equal_weight_mutation_copy_number_expression: CHOL;DLBC;GBM;KICH;KIRC;KIRP;LAML;LGG;LIHC;MESO;PAAD;PCPG;PRAD;SARC;SKCM;THCA;THYM;UCEC;UCS;UVM; mutation_down_weighted: LAML;SKCM;TGCT;THYM;UCEC;UCS; copy_number_down_weighted: PAAD;SKCM;UCEC;UCS; expression_down_weighted: BRCA;OV across non-reference scenarios, indicating that the broad interpretation should emphasize robust groupings over exact branch placement.

Bootstrap co-clustering highlights stable pairs such as: COAD-READ (1.00); MESO-PCPG (1.00); MESO-PRAD (1.00); MESO-THCA (1.00); MESO-UVM (1.00); PCPG-PRAD (1.00); PCPG-THCA (1.00); PCPG-UVM (1.00); PRAD-THCA (1.00); PRAD-UVM (1.00). Projects with relatively low or diffuse co-clustering support include: ACC, BRCA, DLBC, KIRC, LAML, OV, PAAD, SKCM, TGCT, THYM, UCEC, UCS.

Limitations: the current tree uses project-level aggregated traits and first-pass pathway scores, mutation burden is still a mutation-count proxy rather than true mutations per megabase, and the feature set mixes mutation, copy-number, purity/ploidy, and expression summaries with different biological meanings. These results should be treated as molecular similarity analysis and hypothesis generation, not as a literal species-like cancer phylogeny, and they should not be used to infer directional ancestry between cancer types.
